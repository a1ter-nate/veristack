# 07 — Cross-Discipline Zero-Defect Verification (`V30`–`V42`: Lean, Silicon, Safety-Critical & Performance)

Distilled from cross-discipline zero-defect research across **Lean Manufacturing / TPS**, **Hardware & Silicon (ASIC/FPGA)**, **Safety-Critical Software (NASA JPL, DO-178C, SQLite, TigerBeetle, Cleanroom, seL4)**, and **Asymptotic Performance Verification**.

## The 4 Convergent Zero-Defect Laws

1. **Always-On Internal Tripwires Beat External Post-Hoc Detection:** TPS (*Jidoka + Andon*), Silicon (*SVA inline temporal monitors + Boot BIST*), and NASA JPL / TigerBeetle (*production assertion density + paired write↔read assertions*) all embed active self-checking invariants **inside production**, halting on the **first corrupt unit**.
2. **Nominal 1× Pass/Fail Hides Cliffs and Creeping Drift:** Shewhart (*SPC control limits, Nelson rules, $C_{pk}$*), Taguchi (*orthogonal covering arrays + outer-array noise invariance*), and Silicon (*PVT simultaneous corners, CI guardbands, HALT Operating Limit vs Destruct Limit cliffs*) test **margins, drift-before-breach, and simultaneous hostile corners**.
3. **Code Coverage and Isolated `sometimes` Flags Miss Deadly Intersections:** Silicon (*UVM `state × op × fault` cross-coverage closure*), DO-178C / SQLite (*MC/DC compound-condition independence*), and Swarm Testing (*randomized command subsetting*) prove you must measure **interaction closure** and prevent destructive actions from starving deep states.
4. **Defects-by-Omission & Theater Tests Require Mechanical Traceability:** Automotive (*FMEA Control Plans*), DO-178C (*Bidirectional Traceability + IV&V*), and TPS (*Red-Before-Fix + A3 escape ratchet*) block shipping high-risk surfaces without controls, catch unintended agent functionality, and prove bugfix tests fail on the unfixed base commit.

## Engineering Blueprints for `V35`, `V37`–`V40`, and Boot BIST

- **`V35` Taguchi Orthogonal Arrays & Noise Wrapper (`R2`–`R3`):** Generate minimal 2-way/3-way covering arrays (PICT/ACTS) for 6–15 config/flag axes + wrap core suites in a 6-point outer noise matrix (DST fold, `tr-TR`/`de-DE` locales, shuffled JSON keys, CRLF, cold/warm cache).
- **`V37` Functional Cross-Coverage & Swarm / Cleanroom (`R3`, `R5`, `R6`):** Attach a `Covergroup` (`state × action × fault`) to MBT/DST gating on **100% legal cross-bins and 0 `illegal_bins`**; randomly disable ~50% of commands per seed (Swarm mode) so `delete`/`cancel` don't starve deep states; drive R6 Markov traffic matrices from prod wide events.
- **`V38` Relational Non-Interference (`R3`–`R4`):** Execute identical Tenant B sequences in World 1 vs World 2 (injecting arbitrary Tenant A traffic only in World 2) and assert bit-for-bit identical Tenant B responses/state.
- **`V39` Deterministic `1..N` Fault, Torn-Write & Bit-Flip Sweeps (`R4`):** Sweep fallible alloc/IO call indices `k = 1..N` + torn-write crash prefixes + bit-flip corruption, asserting clean error recovery, zero leaked locks/FDs, and crash-prefix linearizability; pair with scheduled twin-vs-live calibration probes.
- **`V40` Formal Logic Equivalence Checking (`R5`):** Symbolically prove `∀x: ref(x) ≡ opt(x)` across refactors/optimizers (`Kani`, `Dafny`, `Z3`).
- **`V41` PVT Corners, HALT Cliffs & Boot BIST (`R6`–`R8`):** Verify simultaneous *Slow/Tight* and *Fast/Race* corners, find exact `OL` vs `DL` cliffs with `<= 75%` CI guardbands, and ship a `< 500 ms` fail-closed production **Boot BIST** (`--self-test` / `/readyz`) verifying config/schema/crypto/downstream boundary scans at startup.

## High-Yield Production Escape Playbooks (Mined From Real Incident Histories)

- **Tri-State Document Query Invariant (`R2`):** Whenever querying optional/backfilled boolean flags in document stores, test every filter/count query against a 3-record fixture `{ missing, false, true }` so `.where(field, "==", false)` cannot silently drop legacy documents or diverge list vs count totals.
- **Contract, OpenAPI & DB-Index Sync (`R3` / `vstack formal-sync`):** Register `contractChecks` in `.verification/control-plan.json` pairing `routes`/`dtos` → OpenAPI/consumer-manifest baselines and `queries` → composite DB index manifests so CI fails on wire-shape or index drift (`contract-artifact-stale`).
- **Dual-Write Parity & Immutability (`R2`–`R3`):** Route mirrored document/subcollection writes through one atomic batch DAO entrypoint, update or return the authoritative in-memory entity, and wrap test inputs in `deepFreeze(...)` to catch shared-reference mutation bugs.
- **UI Stale-Async Races & Re-Entrancy (`R3`):** Test search, pagination, and entity-switch components with delayed out-of-order responses (`req1` resolves after `req2`), asserting `AbortController` or monotonic generation guards prevent stale overwrites, double-click triggers are locked while loading, and entity-scoped subtrees reset via `key={entityId}`.
- **Composed-App Auth Matrix & Deploy Serving Readiness (`R2`–`R5`):** Execute every mounted route against `{ unauthenticated, disabled-user, lower-role, admin }` through the real composed router middleware stack (never mocking auth middleware), and verify scheduler OIDC audiences, required env vars, and bundle/CSS ceilings before deploy (`R5`).
- **Retry Budgets, Idempotency Keys & Blast-Radius Circuit Breakers (`R2`–`R4`):** Enforce remaining-deadline checks before every retry attempt, attach deterministic idempotency keys to external email/payment/webhook calls, negative-cache failing external lookups, and guard bulk delete/reconcile loops with explicit max-count / percentage circuit breakers.
- **Browser Layout Landmarks & Mobile E2E Stability (`R4`–`R7`):** Assert `<main>` landmark presence and `scrollWidth <= clientWidth` across responsive breakpoints in fast CDP/component checks, keep gzipped CSS/JS ceilings enforced in CI, and require `centerElement: true` + keyboard dismissal in mobile E2E flows.
- **Cross-Target Numerical Tolerance & Wire-Layout Parity (`R2`):** Never pin `f32::to_bits()` hashes on transcendental DSP/math outputs across OS targets (assert ULP/dB bounds instead); derive FFI/Wasm/wire strides and enum offsets from a single generated schema and verify with cross-runtime replay.
- **Auth Revision Checks & Protocol Replay Fencing (`R2`–`R3`):** Check monotonic principal/membership `revision` (not just role string equality) inside locked reservation transactions to stop pre-lock TOCTOU and stale-actor execution; run JSONL out-of-order and duplicate replay fixtures against every webhook/stream consumer.
- **Edge Runtime Fidelity & SQL Teardown Parity (`R3`–`R4`):** Whenever `fetch` is mocked in unit tests for edge/Worker code, run an R3 `workerd`/Miniflare smoke check (catches runtime-rejected options like `redirect: "error"`); assert timestamp equality with DB precision tolerance (microsecond/second truncation) and verify every new SQL table is registered in FK-ordered test teardown.
- **Native UI & Clean-Container Smoke (`R3`–`R4`):** Place SwiftUI `.accessibilityIdentifier` directly on interactive controls (never after `.safeAreaInset`), forward child `ObservableObject` `objectWillChange` events, guard simulator `AVAudioEngine` init in XCTest, and run a clean-container smoke check verifying CA certs (`NODE_OPTIONS=--use-system-ca`) and build auth.
- **Cancel-Safety, In-Flight I/O Drain & Teardown Idempotency (`R2`–`R3`):** Drop async futures at every poll point (`consume_budget()`) to prove zero leaked waiters/FDs and cancel-safe `select!` arms; verify `close()`/`dispose()` drains in-flight I/O before closing FDs, retries `EINTR` flushes, and remains idempotent when setup/export throws.
- **Corrupt Persistence, Sentinel Boundaries & HTTP Framing Conformance (`R2`–`R3`):** Fuzz decoders against truncated streams, error sentinels, `0`, `-1`, `INT_MIN`/`LLONG_MIN`, `MAX`, UTF-8 BOM, and non-UTF-8 inputs; test HTTP handlers against duplicate/conflicting `Transfer-Encoding` + `Content-Length`, `204`/`304` body/header stripping, double-decoded paths (`%252e%252e`), and protocol-relative redirects (`//evil`, `\\evil`).
- **Compound-Op RBAC, Concurrent Lifecycle Races & ORM Complex-Type Roundtrips (`R3`–`R5`):** Test authorization across compound sub-operations (`TXN` sub-ops, `PrevKv`, lease attach, script ACL contexts, TLS CRL); run `-race`/TSAN/Loom stress over concurrent shutdown, snapshot reload, and replication; verify ORM optional nested complex-type `non-null → null → non-null` + `DetectChanges()` roundtrips and real-DB RLS DDL migration dry-runs.
- **Affine Resource Linearity, CVE Taint Sinks & Jepsen Monotonic Leases (`R0`–`R4`):** Treat handles (`openSync`, `pool.connect`, streams, `AbortController`, listeners) as linear obligations closed on every exit path (`affine-unreleased-resource`, `affine-use-after-close`, `affine-uncleaned-effect-subscription`); block CWE-22/94/116/252/789/918/1287/1333 sinks via AST taint & bounds checks; tie distributed leases to monotonic clocks + fencing tokens (`jepsen-wall-clock-lease`); guard SQL DDL migrations with `SET lock_timeout`; block agent reward-hacking diffs (`diff-agent-oracle-tampering`); and prove verifier soundness with `vstack bench . --fail`.
- **AI-First Agent, MCP & Durable-Checkpoint Playbooks (`R1`–`R3`):** Test streaming tool deltas for concatenated-JSON parity and premature SSE EOF settlement (reject pending RPC maps in `finally` + propagate `AbortSignal`/`aclose()` to child subgraphs); verify durable checkpoints with double-replay journal tests (pre-assign IDs before persist, strip ephemeral provider item IDs, enforce migration tombstones so deleted credentials never resurrect); keep approval snapshots immutable post-validation; scrub secrets across *all* channels (`text`, `thinking`, `tool_call` args, `error`) sorted longest-first; place tool metadata (`exitCode`/`truncated`) before large output blobs; and test shell installers headless (`</dev/null`, `set -euo pipefail`, no secrets in argv).
- **Auth, Testing Harness, Rust Safety & HTTP/Messaging Playbooks (`R1`–`R3`):** Normalize paths before authz matching and key auth/permission caches by `(tenantId, userId, roleEpoch)`; enforce OAuth grant policy parity across refresh/device/token-exchange paths and check destination permissions on RBAC reparent/move operations; add pre-dispatch header/body read timeouts (Slowloris defense); roll back DB/DOM state on test retries and coalesce watch-mode restarts; canonicalize `NaN` in PBT/shrinking strategies and lock strategy registries; evict faulted async promises/tasks from caches; propagate correlation/tenant context across outbox/retry boundaries and assert outbox message ordering under retries; and escape terminal control/BiDi sequences in CLI output.
- **Database, Compiler, Cloud-Native & Enterprise Runtime Playbooks (`R1`–`R5`):** Hold commit barriers across WAL append + `fsync` + in-memory publish and bound MVCC/catalog GC strictly below the minimum active snapshot watermark; never globally memoize recursion-depth `Overflow` results in compilers/typecheckers, emit deterministic symbol/diagnostic orders independent of hash/pointer/worker order, and verify parser/optimizer rewrites via differential corpus oracles; drain readiness probes before closing listeners, deep-copy shared informer cache objects before mutation, decouple leader-lease renewal from worker contexts, freeze shard rebalancing during backoff, and cap dynamic metric label cardinality; keep SSR state strictly request-scoped (no module-level globals), validate DI scope lifetimes (`ValidateScopes` + `ValidateOnBuild`), ensure `acks_late` tasks are idempotent with `visibility_timeout > max(time_limit, eta)`, and enforce middleware security ordering (`ExceptionHandler -> Routing -> Cors -> Auth -> Authz -> Antiforgery -> Endpoints`).
- **Black-Hole Immune System & Historical Replay Verification (`R0`–`R5`):** Define repo-owned choke points in `.verification/chokepoints.json` (plus `clippy.toml` `disallowed-methods`/`disallowed-types` and `.oxlintrc.json` `no-restricted-globals`) so dangerous primitives (`fetch`, raw `std::fs`, unredacted `url::Url`) are structurally uncallable outside blessed wrappers; pin third-party GitHub Actions to 40-char commit SHAs with explicit `permissions:` and `persist-credentials: false`; enforce `vstack diff-cheats --fail` on PRs to block suppression injection, strictness downgrades, assertion deletion, and removed CI gates; run `vstack laws --verify --fail` so declared laws execute mechanical witnesses; and pair static gates with `R2–R5` PBT/MBT/differential/Loom tests (real-world replay shows ~85% of production bugs are domain/protocol/race semantics that only executable property/state-machine oracles can catch).
- **Multi-Surface Agent App & Wire-Budget Playbooks (T3 Code / `pingdotgg` Immune Standard, `R1`–`R7`):** Enforce `--report-unused-disable-directives` and `knip --exports --production`; drain async event workers via `Deferred`/`TestClock` instead of sleeps, polling loops, or `requestAnimationFrame` waits; render browser tests via `await using screen = await render(...)` (`AsyncDisposableStack` cleanup); gate wire/projection payload budgets with `Required<...>` contract tests so every opt-in field is budget-tested and never route high-frequency tool/command output deltas through durable event logs; verify multi-surface parity (web/desktop/mobile/MCP/reverse-states), ban `pkill -f` pattern kills in dev/agent scripts, ban continuously repainting CSS/Reanimated loops beside heavy content, and prove user-visible bug fixes with red-before-fix scenario runs (`scenarios:prove` / `vstack red-before-fix`).
