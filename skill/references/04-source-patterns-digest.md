# 04 — Source Patterns Digest (Lineage & Citations)

Traceability map of the public engineering literature, open-source repositories, and cross-discipline zero-defect frameworks that inspired **Veristack** (`vstack`). Veristack is an independent, clean-room MIT implementation; no third-party source code is copied from the projects below.

| Source | License / Type | Key Ideas & Principles Reflected in Veristack |
| :--- | :--- | :--- |
| **Matteo Vaccari — [*Tests as Data*](https://martinfowler.com/articles/tests-as-data.html)** | Public article | Black-box customer tests as the human-AI contract; CSV/JSON/YAML test tables for stateless matrices; constrained external test DSLs; diffable printers; non-prod side channels; Digital Twins; File-Change Matrix Lock; independent oracles. |
| **John Ousterhout — *A Philosophy of Software Design*** | Book | Deep modules, narrow interfaces, information hiding, and code locality. |

| **[`@interfere/landmines`](https://github.com/interfere-inc/landmines) & [`dmmulroy/anti-slop`](https://github.com/dmmulroy/anti-slop)** | MIT / MIT | Oxlint guardrails making the honest testing and typing path the only one that lints (`no-test-doubles`, `strict-msw`, `no-fixed-sleep`, `no-flake-masking`, `no-conditional-expect`, `no-chained-type-assertions`, `no-comments`, auto-shrinking allowlists). |
