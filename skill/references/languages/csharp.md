## 2. Drop-In `Directory.Build.props`

```xml
<Project>
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <LangVersion>latest</LangVersion>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <TreatWarningsAsErrors>true</TreatWarningsAsErrors>
    <AnalysisLevel>latest-all</AnalysisLevel>
    <AnalysisMode>Recommended</AnalysisMode>
    <EnforceCodeStyleInBuild>true</EnforceCodeStyleInBuild>
  </PropertyGroup>

  <ItemGroup>
    <ProjectReference Include="path/to/VStack.Analyzers/VStack.Analyzers.csproj"
                      OutputItemType="Analyzer"
                      ReferenceOutputAssembly="false" />
  </ItemGroup>
</Project>
```

### Enforced Roslyn Rules (`VSTACK001` – `VSTACK004`, All `Error` Severity)

| Rule ID | Analyzer | Enforces |
| :---: | :--- | :--- |
| **`VSTACK001`** | `NoCommentsAnalyzer` | Bans prose/excuse comments (`//`, `/* */`, and private `///`). Allows `WARNING:`, `SAFETY:`, SPDX/license headers, `<auto-generated />`, tool directives, and `///` XML docs on `public` declarations. |
| **`VSTACK002`** | `ExplicitStateMachineAnalyzer` | Bans all 4 implicit state machine patterns: `>= 2` lifecycle `bool` flags (`implicit-sm-boolean-soup`), nullable state-bag DTOs (`Status`/`State`/`Phase`/`Stage`/`Mode` + `>= 2` nullable siblings), scattered direct state mutations across `>= 2` methods outside `Transition`/`Reduce`, and non-exhaustive `switch` statements/expressions lacking an explicit throwing `default` / `_ => throw`. |
| **`VSTACK003`** | `NoSuppressionOrSwallowingCatchAnalyzer` | Bans unjustified `#pragma warning disable` (missing `// WARNING:`/`// SAFETY:`/`-- reason`), `[SuppressMessage]` without a non-empty `Justification`, and empty `catch { }` / `catch (Exception) { }` blocks. |
| **`VSTACK004`** | `TestIntegrityAnalyzer` | Compile-time C# equivalent of `@interfere/landmines` inside `[Fact]`/`[Theory]`/`[Test]`/`[Property]` methods: bans `Thread.Sleep`/`Task.Delay`, `DateTime.Now`/`UtcNow`/`Random.Shared`/`new Random()`, `Environment.SetEnvironmentVariable`, `Assert.Pass`/`Assert.True(true)`/`Assert.Equal(x, x)`, one-sided conditional `if (...) { Assert.* }`, and `Skip = ...` / `[Ignore]`. |

### Explicit State Machine Idiom (C#)

Use a closed `abstract record` with a `private` constructor and `sealed record` variants (disable `CA1034` in `.editorconfig` solely for closed nested record hierarchies):

```csharp
public abstract record OrderState
{
    private OrderState() { }
    public sealed record Pending(int AmountCents) : OrderState;
    public sealed record Authorized(int AmountCents, string AuthCode) : OrderState;
    public sealed record Shipped(int AmountCents, string AuthCode, string TrackingId) : OrderState;
    public sealed record Cancelled(string Reason) : OrderState;
}
```
